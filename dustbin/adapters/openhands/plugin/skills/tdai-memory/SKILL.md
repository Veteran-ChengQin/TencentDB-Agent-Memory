# TDAI Memory Search

Use `tdai_memory_search` when prior engineering rules, preferences, or bug-fix
experience may help the current task. Use `tdai_conversation_search` when the
exact details of a previous work session are needed.

Treat recalled memory as advisory context. Verify file paths, APIs, tests, and
repository behavior against the current checkout before editing code.
